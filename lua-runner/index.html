Lua 在线运行器

在浏览器里写 Lua、跑 Lua，并模拟 OpenResty / Nginx 的 ngx API

Lua 5.3Fengari 虚拟机OpenResty Mock纯前端 · 无需后端
main.lua行 1，列 1
Ctrl / Cmd + Enter 运行 · Tab 缩进0 字符
运行输出
点击“运行”执行代码，输出会显示在这里。
响应状态200 OK
查看模拟的响应体（ngx.print / ngx.say 输出）
就绪
模拟请求与标准输入（用于 ngx.req / io.read）
运行时：Fengari（用 JavaScript 实现的 Lua 5.3 虚拟机），代码在浏览器本地执行，不会上传到服务器；
支持 Lua 协程、元表、UTF-8、位运算等 5.3 语法，输出与返回值会直接显示在右侧控制台。
OpenResty 部分为模拟实现：已覆盖 ngx.say / ngx.print / ngx.log / ngx.exit / ngx.var / ngx.header /
ngx.req / ngx.re / ngx.shared / ngx.timer / ngx.thread / ngx.md5 / ngx.encode_base64 / ngx.crc32 /
cjson 等常用 API，但 Nginx 本身、网络 IO、真实子请求、SSL 等能力无法在浏览器复现，行为与生产环境存在差异。
正则使用 Lua 模式近似 PCRE，不支持分支 | 与前后瞻断言。
